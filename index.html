Andrew Cassidy BSc (Hons) MBCS

Head of Infrastructure @ Orbital Net

I build and run the systems an ISP runs on, from the network itself (routing and anycast) through to the platforms on top: RADIUS, VoIP and the automation that ties them together. Much of it is bespoke, because the off-the-shelf option rarely fits.

I like designs where a few simple rules produce the behaviour you want, the way a shared queue makes topology changes invisible: add workers or move services and nothing else needs to know. When I find myself writing a special case, it usually means the model is wrong, not that the code needs another branch.
